MFEM/MGIS is a C++ library for nonlinear thermo-mechanical simulations on HPC
systems, combining [`MFEM`](https://mfem.org/) finite elements and
[`MFront`](https://thelfer.github.io/tfel/web/index.html) behaviours through
[`MGIS`](https://github.com/thelfer/MFrontGenericInterfaceSupport).

The goal and features of MFEM/MGIS are described in its
[JOSS paper](https://doi.org/10.21105/joss.07719).

- [Documentation](https://thelfer.github.io/mfem-mgis/), with the
  [installation guide](https://thelfer.github.io/mfem-mgis/installation_guide/installation_guide.html)
  and a [tutorial](https://thelfer.github.io/mfem-mgis/user_guide/tutorial.html) on a notched beam
- [API reference](https://thelfer.github.io/mfem-mgis-doxygen/index.html)
- Examples in [mfem-mgis-examples](https://github.com/latug0/mfem-mgis-examples)
  and [mm-opera-hpc](https://github.com/rprat-pro/mm-opera-hpc)
